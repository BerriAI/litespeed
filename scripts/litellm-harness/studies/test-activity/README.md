# Test activity reminder activation

The old reminder counted only commands with a safely attributable check identity. Environment-prefixed Python commands often ran tests without such a receipt, leaving the reminder inactive. v24 counts completed test-like jobs separately, without changing pass/fail receipts or counting repeated polls as new tests.

[Plan](plan.json) compares four v24 attempts against four already planned Medium v22 controls on MCP authentication and router strategy isolation. These control identities were selected before their results existed; they are reused once and must not be relaunched. The public copy removes local paths while retaining trial identities and commits.

Check observed `testFocusNotices` as well as completion, behavior and elapsed time. An activated reminder is not evidence that it improves outcomes. Original acceptance scores remain intact, including the router oracle's exact private-helper requirement. This study is development selection.
